# mysetup Scoop bucket

The mysetup command-line client for Windows (preview, not code-signed). Install:

```powershell
scoop bucket add mysetup https://github.com/mysetupai/scoop-bucket
scoop install mysetup/mysetup
```

Version 0.1.0 was cross-compiled and import-checked; Windows runtime verification is still pending.

See https://mysetup.ai/download.
